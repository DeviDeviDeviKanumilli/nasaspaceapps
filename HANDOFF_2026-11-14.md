## Project in one paragraph

NASA Space Apps 2026, challenge "Identify Earth locations that analog the permanent Moon base
locations and Mars". Princeton local event; submission closes Sun 15 Nov 11:59 PM ET. The system
compares real planetary data (LOLA Moon south-pole DEM; MOLA–HRSC Mars DEM; published geology) with
Earth data everywhere, with no hand-picked or famous-site list, and reports measured distances
(never percentages or blended scores). Two independent pathways, terrain and geology/process, share
one 10 km window grid; each nominates candidates and each candidate is measured by both.

## Decisions that are settled (don't reopen without new evidence)

- Two pathways, no blended score; nomination by Pareto fronts (terrain) and evidence tiers (geology).
- Terrain estimator: least-squares plane over a disc of diameter L; slope = plane tilt; roughness =
  RMS residual; L = 400/800/1600/3200 m on a 100 m grid (Mars: 1600/3200 only).
- Distances: 1-D Wasserstein from 50 midpoint quantiles; worst scale over baselines; units kept.
- Copernicus GLO-90 + WorldCover mask for the global run; USGS 3DEP bare earth for the region.
- Website reads only run outputs; text from fixed templates; coverage map; "not measured" labels.
- Field data (D435) documents the site and checks lidar; it does not validate planetary matching.

## State of the code (`engine/`)

## Results so far (real data)

- Lunar sites differ from each other by 3.7–11.3° worst-scale slope W1 (400 m–3.2 km). Each site's
  own quarters differ from the whole box by 1.2–13°. These are the yardsticks for every distance.
- Moon slopes keep their size from 400 m to 3.2 km (ratio 0.67–1.02); river-cut Earth terrain
  doesn't (0.38–0.78 in control tiles). This "scale signature" is the headline terrain finding.
- Regional run (150 km around Plainsboro, 3DEP, 240–960 m): no window is closer to any lunar site
  than the lunar sites are to each other. Best distance to the Connecting ridge is 4.7°; the
  Connecting ridge vs de Gerlache rim distance at the same baselines is 2.6°.
- Global geology run: 658 Jezero-type and 365 InSight-type G4 windows (exposed basalt + process
  partner), led by the Puna, Afar, northern Kenya, Sudan, Jordan/Syria and Libya basalt fields.
  Weakness: the partner counts at any fraction; set a minimum (e.g. 10%) before the frozen run.
- Regional geology: only G1 (mapped basalt ~31–36 km NNE and ~145 km WSW), almost unexposed.
